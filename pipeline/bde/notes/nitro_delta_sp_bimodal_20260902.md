# nitro 组 Δ_SP "双峰" 的细查(2026-09-02)

**背景**:DFT 仲裁 round2(`data/cross_benzoin/homo_v6/dft_bde_geom_arbitration_round2/merged_round2.csv`,
n=111)里,nitro 组(n=18)的 `Delta_SP` 方差异常大(std ≈ 21,接近均值本身),
PROGRESS_20260714.md 〇-14 记为"真实、明确、但目前解释不了的双峰现象",并已排除
"是否含硫 / 环数 / 重原子数"这几个全局结构描述符。本次补齐机理。

约定:`Delta_SP = bde_gxtb - bde_dft_sp`(负 = g-xTB 相对 DFT 低估),
`Delta_geom = bde_dft_sp(GFN2几何) - bde_dft_opt(DFT几何)`。

## 结论:不是真正的 level-of-theory 双峰,是 g-xTB 自身在少数 nitro 上失败

1. **DFT 侧是自洽的**:所有 18 个分子的 `|Δ_geom| < 4.4`,POS 组 `|Δ_geom| < 2.3`,
   即 GFN2 几何上的 DFT-SP ≈ DFT-opt 几何上的 DFT。DFT 数字没有双峰。
2. **是 g-xTB 在 POS 组给出了物理上不合理的高 BDE**:醛 formyl C–H BDE 的典型值
   ≈ 88–89 kcal/mol,重取代也很少超过 ~95。POS 组里
   **id 86691 (g-xTB 131.9)、119366 (100.1)、121593 (105.8) 三个 g-xTB BDE ≥ 100**,
   对应 DFT 只有 68–96 —— g-xTB 高估 +10 到 +37 kcal/mol。这三个分子主导了整个 nitro 组
   Δ_SP 的正尾。
3. 另外两个 POS(73566 / 73568,g-xTB 82.6 / 87.7,DFT 75–77,是一对近邻 id,可能是
   结构类似的一对)幅度小(Δ_SP ≈ +7 到 +11),可能只是正常方法差的噪声,不是 g-xTB 失败。
4. **剔掉这 3 个 g-xTB 失败点后,nitro 组的 Δ_SP 是单峰的**,与其它所有官能团一致
   (强负,g-xTB 系统性低估 ~20–30 kcal/mol,来自 single-point 方法层级)。
5. **判别量是 `bde_gxtb_kcal` / `bde_dft` 本身**(g-xTB 输出是否物理合理),不是任何全局
   分子结构描述符 —— 这解释了为什么 PROGRESS 里用 RDKit 结构描述符对不上:因为这不是
   "某类 nitro 结构 DFT-SP 效应反号",而是"g-xTB 数值在这几个分子上崩了"。

失败的 3 个分子共性:polynitro(多个 −NO₂)或带脂肪链的 nitro,芳环数偏少、fcsp3 偏高。
但样本太小(n=3),不足以给出可靠的结构规则,不强行编。

## 对建模的实际影响 / 建议

- 这些是 **g-xTB 标签离群点**,不是模型容量问题。数量很少(仲裁样本里 3/18,外推到全库
  大概每千个 nitro 醛有几个)。
- `pipeline/bde/qc.py` 的 `qc_filter` 对醛用 `phys_max=250`、`k_mad=6`。醛 formyl C–H
  BDE 中位数 ~88、MAD ~4–6 → `med + 6·MAD ≈ 115`。所以 g-xTB BDE = 131.9 大概会被 MAD
  规则挡掉,但 **100–106 的那两个会漏网**,作为被污染的标签进入训练,正好落在
  nitro / 强 EWG 这条"最难官能团"残差尾巴上。
- **便宜的改进方向**:给醛侧 BDE 加一个更紧的物理上限(比如 formyl C–H ≤ ~105–110
  kcal/mol),或对 nitro 子集单独设阈,能去掉一小批毒标签。**不要现在直接改 `qc.py`**
  ——它是所有 B0–B6 共用的,改动要单独做前后对照评估(会同时影响历史排名数字的可比性)。
  记为独立待办。
