## 1. 2026-07-13 to 2026-07-14 — real dataset ingest + homo champion packaging

1. **Pulled the real GitHub `candidates_v3` dataset** (2M unordered / 4M directed pairs) via a
   rootless `git-lfs` static-binary install. It ships its own molecule-disjoint 80/10/10
   train/val/test split (`inchikey_split_map.parquet`).
2. **Found a split-consistency defect in the earlier custom sampler**: 184/598 (31%) of round-1's
   pairs had donor and acceptor in *different* splits, because the custom generator drew pairs
   freely from the aldehyde pool. Decision: from round 3 onward, sample directly from
   `candidates_v3`'s own pair list.
3. **Built + ran product-BDE compute** (`calc_bde_gxtb_product_cross.py`) for rounds 1-2. At n≈598,
   donor/acceptor BDE and product BDE both showed **no measurable signal** — the real homo-side BDE
   gain (1.525→1.503) is undetectable against ~2.7 kcal residual noise at this sample size;
   scale, not more features, is the lever.
4. **Closed the ENSEMBLE72 homo-champion packaging gap** (deferred twice before): new
   `src/benzoin_dG/_ensemble72_inference.py` adapter + `predict_dG_champion()`. Resolved the
   numpy≥2 `RandomState` unpickling problem durably via an `envs/bde_lite` subprocess bridge
   (`_ensemble72_predict_subprocess.py`). Validated on benzaldehyde: predicted 3.616 vs true DFT
   label 3.591.
5. **Round 3 sampling** (`sample_round3_from_candidates_v3.py`): 4,200 pairs / 8,400 directed rows,
   sampled directly from `candidates_v3` train-split blocks, category-balanced.
6. **Found + fixed a silent chunk-failure bug** in `submit_cb_featurize_array.sh`: a trailing
   `echo ... exit=${PIPESTATUS[0]}` made SLURM record every chunk as COMPLETED even when the
   Python process hard-failed. 16/84 round-3 chunks had silently dropped ~1,600 rows. Fixed to
   capture `RC=${PIPESTATUS[0]}` and `exit "$RC"`.

## 4. 2026-07-16 — ensemble shipped + unification reverses + round 6

1. **MLP+XGB ensemble SHIPPED** as a packaged joblib artifact (`train_cross_ensemble.py`,
   `MLPXGBEnsemble` class): round1-5 frozen holdout MAE 2.983 → **2.633**, R² 0.865 → **0.898** —
   the best-validated cross model at that point.
2. **Homo+cross unification re-test at 17,270 rows**: still additive but **benefit halved** —
   cross-rows-only CV MAE −1.0% (down from −1.9% at 4,120 rows).
3. **Round 6 launched** (`job 24667830`, 4,000 pairs re-scored from screen10k's unspent remainder
   against the round1-5 champion — **zero new xTB/g-xTB cost**).
4. **Round 6 combined table** (25,176 rows): single-XGB CV MAE **2.276**; ensemble CV MAE
   **2.034**, frozen holdout MAE **2.582** / R² 0.897 — the ensemble's lead over single-XGB
   widened to −17.6%.
5. **GNN-transfer stacking correction**: an experiment first read as a null result (p=0.4556,
   coin flip) turned out to be an untuned-hyperparameter artifact. With `lr=3e-4, patience=25,
   extra_val_frac=0.15`: blend beats ensemble with **p=0.9261**, 90% CI mostly negative. A
   concurrent BDE session had briefly (and mistakenly) touched this project — its legitimate work
   (the `--lr` flag, round-7 DFT-SP submission) was verified and kept; one wrong-schema duplicate
   job was cancelled.

   — the first time homo data made cross predictions worse. Recommendation: stop using that

## 5. 2026-07-17 (overnight, autonomous) — round 7, five diagnostics, scaffold-disjoint rebuild, BDE takeover

1. **Round 7 completed** (DFT-SP + BDE + assembly + retrains) → **32,456 rows / 16,241 pairs**.
   Ensemble CV MAE hit a new best **1.883** (old leaky split). GNN-stacking correction confirmed
   across 3 seeds (2.385 ± 0.011).
2. **Homo+cross unification finding held**: reversed / harmful at this scale — stop the recipe.
3. **Five "step outside habitual thinking" diagnostics** (mirroring gaps vs homo's validation
   suite):
   1. **Phosphorus-containing aldehydes are the clearest error driver** — MAE 4.14 vs 2.22
      baseline (n=506). Boron (2.53) and nitro (2.39) secondary.
   2. **Active-learning uncertainty IS calibrated** — Spearman 0.258, decile-binned MAE
      monotonic 1.66 → 3.93. Rounds 2-7's sampling is validated retroactively.
   3. **Per-pair A→B vs B→A error gap is large** (mean |Δ| = 1.738, comparable to overall MAE)
      even though the aggregate is symmetric — flagged, not yet explained.
   4. **candidates_v3's 2M sample has the same structural diversity as an unrestricted
      full-library draw** — its narrowness is deliberate category rebalancing, not a blind spot.
   5. **candidates_v3's official molecule-level split leaks scaffolds severely** — 93% of the
      29-row frozen holdout has a leaked scaffold; 83.2% at full-library scale. Leaked rows MAE
      2.99 vs genuinely-novel 3.46 (+16%).
4. **User authorized an overnight scaffold-disjoint rebuild**:
   - New split via a single **global greedy largest-scaffold-first bin-packing pass** across
     46,343 Murcko scaffolds → 176,687 / 22,086 / 22,086 (80/10/10 exactly). (Naive per-`cho_class`
     assignment was found fundamentally broken: 63% of molecules' scaffolds span >1 class.)
   - Re-labeled round1-7 pairs: clean-train **19,687**, mixed 36.5% (discarded),
     **clean-test grew n=29 → n=450 (15.5×)**.
   - Retrained champion + ensemble (`scaffold_disjoint_v1/`): raw numbers (2.448 / 2.256) *look*
     better than the old leaky ones, but that is a **test-set composition artifact** (new test
     skews toward easier reaction-type categories). Per-category / reweighted analysis: honest
     cost is a real, modest **+0.14 to +0.30 MAE** vs CV.
   - GNN retrained on the new split (`train_gnn_scaffold_disjoint_v1/`): blend gain shrank from
     −0.298 (old split) to **−0.041**, but bootstrap (B=20,000, n=450) gives 90% CI (−0.080,
     −0.003) entirely negative, **P(blend better) = 0.9632** — confirmed real.
   - **Packaged `predict_cross_champion.py`** (`CrossBenzoinBlendPredictor`, single-environment,
     auto-reads the blend weight from GNN metadata). Verified to reproduce training MAE exactly
     (2.2151 vs reported 2.215).
   - **1,263,002 scaffold-train-eligible, not-yet-labeled pairs** remain for round 8+.
5. **Took over the BDE-prediction project** (`pipeline/bde/`) per explicit user request
