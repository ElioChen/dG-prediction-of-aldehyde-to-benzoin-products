# benzoin-dg hard-set dashboard

The molecules our models predict worst — across every task (homo BDE aldehyde /
homo BDE product / homo ΔG / cross ΔG), both reactant and product side — tagged by
*why* they are hard. Meant to be a **dynamic** target: it shrinks as we overcome
each class of difficulty, and the Progress tab shows what has dropped out.

## Run

```bash
# 1. (re)build the data — do this after ANY model retrain
/home/schen3/venv/nhc-workflow/bin/python pipeline/analysis/build_hard_set.py

# 2. serve the dashboard
/home/schen3/venv/nhc-workflow/bin/streamlit run dashboard/hard_set_app.py
# then open the printed URL (default http://localhost:8501)
```

`build_hard_set.py --top-frac 0.15 --min-abs-res 3.0` — tune what counts as "hard"
(default: worst 15% by |residual| per task). `--no-history` skips the snapshot.

## Cause tags

- `gxtb_baseline_failure` — |g-xTB baseline − DFT| ≥ 15 kcal; Δ-learning can't recover
  a broken baseline. Concentrated on P (esp. P=O / phosphonium), sulfonyl, heavy amide.
  See `pipeline/analysis/notes/gxtb_baseline_failure_hardtail_20260902.md`.
- `fg:*` — known-hard substructure (phosphine oxide, phosphonium, phosphorus, sulfonyl,
  sulfinyl, nitro, N-oxide, imine, amide, triflate, boron, azide, diazo).
- `aliphatic` — no aromatic ring (systematically harder than aromatic).
- `flexible` — ≥12 rotatable bonds or MW ≥ 500 (noisier single-conformer label).
- `heavy_heteroatom` — Se / Te / As / Br / I.
- `high_uncertainty` — model's own PI width in the top decile (what `route_to_dft` flags).
- `implausible_label` / `implausible_baseline` — value outside the task's physical window
  (data-quality outlier, not model difficulty).
- `unexplained` — no reason found yet. **The frontier.**

Data + snapshots: `data/analysis/hard_set/` (`hard_set.parquet`, `hard_set_summary.json`,
`hard_set_history/<UTC>/`).
